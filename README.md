# WordLoop 🔁

**Интерактивный бесконечный тренажёр слов с ИИ.**  
Вставляешь любые слова (или готовые пары) → ИИ отфильтрует мусор, дубликаты, найдёт точный перевод и составит мнемонику → карточка со словом → вспоминаешь перевод → не вспомнил, жмёшь кнопку → карточка переворачивается → и слово возвращается в бесконечный цикл повторений, пока сам не решишь ливнуть.

---

## ⚡ Особенности

- 🧹 **Умный фильтр и парсер**: автоматически удаляет дубликаты, эмодзи, мусорные ссылки и цифры. Понимает как одиночные слова (`apple`, `serendipity`), так и готовые пары (`apple - яблоко`, `dog : собака`).
- 🤖 **ИИ-перевод + Мнемоники**: переводит на любой из 20 языков и генерирует короткую запоминающуюся подсказку-мнемонику.
- 🆓 **Работает сразу без API («апи я сам дам потом»)**: если API-ключ ещё не настроен, сайт автоматически использует встроенный бесплатный авто-переводчик. Никаких ошибок и блокировок!
- 🔑 **Поддержка любых моделей**: можно подключить OpenAI (`gpt-4o-mini`), Groq (`llama-3.3-70b-versatile` — бесплатно и быстро), OpenRouter или DeepSeek через настройки в один клик.
- 🔁 **Бесконечный Spaced Repetition цикл**:
  - Карточка выходит — ты вспоминаешь перевод.
  - Не помнишь — жмёшь **«Показать перевод»** (или `Space` / клик).
  - Карточка переворачивается в 3D.
  - Жмёшь **«Не помню»** (`1` / `←`) — слово вернётся уже через 1 карточку, а в новом раунде пойдёт первым!
  - Жмёшь **«Запомнил»** (`2` / `→`) — счётчик закрепления растёт, слово откладывается дальше.
  - Цикл крутится бесконечно, пока не нажмёшь **«Ливнуть ✕»** (`Esc`).
- 🔊 **Озвучка & Звуковые эффекты**: синтез речи (Web Speech API) на русском, английском и ещё 18 языках + приятные звуковые эффекты переворота и ответов на Web Audio API.
- 📊 **Детальная статистика**: раунды, точность в %, время сессии, соотношение знал/забыл, счётчик выученных слов намертво.
- 💾 **Автосохранение**: прошлая сессия и настройки сохраняются в `localStorage` — можно продолжить тренировку после перезагрузки.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| <kbd>Space</kbd> / <kbd>Enter</kbd> / <kbd>↓</kbd> | Показать перевод / перевернуть карточку |
| <kbd>1</kbd> / <kbd>←</kbd> | Не помню (слово возвращается в начало) |
| <kbd>2</kbd> / <kbd>→</kbd> | Вспомнил / запомнил (streak +1) |
| <kbd>S</kbd> | Озвучить текущую сторону карточки голосом |
| <kbd>M</kbd> | Включить / выключить звуки |
| <kbd>Esc</kbd> | Ливнуть (открыть экран с результатами) |

## 🚀 Деплой на Vercel за 1 минуту

Репозиторий полностью готов к деплою на Vercel (zero-config):

1. Зайди на [vercel.com/new](https://vercel.com/new)
2. Выбери репозиторий `wordloop` и нажми **Deploy**.
3. **API-ключ (по желанию):**
   - **Вариант 1 (серверный ключ в Vercel)**:  
     В настройках проекта Vercel → *Settings* → *Environment Variables* добавь:
     - `OPENAI_API_KEY` — твой ключ (OpenAI, Groq или OpenRouter)
     - `OPENAI_BASE_URL` — *(опционально)*, например `https://api.groq.com/openai/v1`
     - `OPENAI_MODEL` — *(опционально)*, например `gpt-4o-mini` или `llama-3.3-70b-versatile`
     
     Тогда запросы идут через защищённую Serverless Function (`api/ai.js`), ключ наружу в браузер **не утекает**.
   - **Вариант 2 (быстрый в браузере)**:  
     Нажми ⚙ в шапке сайта и введи ключ — он сохранится исключительно в твоём личном `localStorage`.
   - **Вариант 3 (без ключа вообще)**:  
     Сайт сразу работает в автономном бесплатном режиме!

## 💻 Локальный запуск

Сайт написан на чистом HTML, CSS и Vanilla JS — никаких тяжёлых сборщиков не требуется.

```bash
# Клонировать
git clone https://github.com/iboshka24/wordloop.git
cd wordloop

# Запустить локальный сервер
npx serve .
# или
python3 -m http.server 3000
```

Открой [http://localhost:3000](http://localhost:3000) в браузере.
